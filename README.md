# 바이브코딩 모의고사

CJ올리브네트웍스 'AI 역량진단(바이브 코딩 테스트)' 대비용 연습 사이트예요.
시험 플랫폼처럼 한 화면 안에서 문제를 보고, 화면 안 AI와 대화하며 FastAPI로 구현하고, 제출하면 숨은 테스트와 AI로 채점해요.

## 쓰는 법

홈(바탕화면)에서 **새 모의고사 · 이전 기록 · 보고서 열람 · 설정**으로 들어가요. 시험 중에도 메뉴의 '홈'으로 잠깐 나갔다가 '이어서 풀기'로 돌아올 수 있고, '나가기'로 그만둘 수 있어요.


1. '설정'의 'Claude API 키'에 Anthropic 콘솔에서 만든 키(`sk-ant-...`)를 넣어요.
   - 키는 이 브라우저의 localStorage에만 저장되고, `api.anthropic.com`을 부를 때만 써요. 저장소에는 키가 없어요.
   - 콘솔에서 월 사용 한도를 걸어 두는 걸 권해요.
2. 직무·제한 시간·문제 유형·AI 성능(상 Opus / 중 Sonnet / 하 Haiku)을 고르고 문제를 뽑아요.
3. 시작을 누르고 AI 탭에서 대화하며 코드 탭에 답안을 써요. ▶ 실행, 테스트(pytest)로 확인할 수 있어요.
4. 제출하면 숨은 테스트로 구현 완성도를 매기고, 대화 기록을 보고 대화 맥락·검증·토큰 효율·보안을 채점해요.

## 기록·보고서 저장

채점이 끝나면 점수표, 숨은 테스트 결과, 프롬프트 첨삭, 면접 꼬리질문, AI 대화 전체, 최종 코드를 담은 보고서(.md)가 만들어져요.

- **내려받기**: 결과 화면의 '보고서 내려받기'
- **GitHub 비공개 저장소에 자동 저장**: 시작 화면 '기록 저장소'에 저장소(예: `아이디/vibe-mock-records`)와 토큰을 넣으면 채점할 때마다 저장돼요.
  - `reports/YYYY-MM/날짜_시각_문제_점수.md`: 보고서
  - `records/index.json`: 지난 기록 목록 (사이트의 '지난 기록'이 이 파일을 읽어요)
  - 토큰은 Fine-grained token으로, 그 저장소 하나만 고르고 권한은 Contents: Read and write만 줘요. 토큰은 브라우저 localStorage에만 저장돼요.

## 채점 기준 (연습용)

| 항목 | 배점 | 방식 |
|---|---|---|
| 구현 완성도 | 35 | API 과제는 숨은 테스트 통과율 |
| 대화 맥락 | 20 | AI 채점 |
| AI 결과 검증 | 20 | AI 채점 |
| 토큰 효율 | 15 | AI 채점 (API가 알려 준 실제 토큰 수 사용) |
| 보안·책임 | 10 | AI 채점 |

실제 시험의 시간·도구·배점은 공개되지 않았어요. 위 기준은 설명회에서 나온 이야기와 공개된 AI 역량평가 플랫폼 자료를 바탕으로 만든 추정이에요.

## 구조

| 경로 | 내용 |
|---|---|
| `index.html` | 화면 전체 (문제 은행, 숨은 테스트, 채점 로직, Claude API 호출) |
| `cm.js` | 코드 에디터 CodeMirror 5.65.18 (+ 파이썬 문법 색, 괄호 짝) 묶음 |
| `py-worker.js` | 답안 코드를 브라우저 안 파이썬(Pyodide)으로 실행하는 웹 워커 |
| `py/` | Pyodide 0.29.5와 패키지(FastAPI, pandas, numpy, scikit-learn, pytest 등) |

- `py/` 아래 `.whl`·`.zip` 파일은 원래 이름 뒤에 `.wasm`을 붙여 두었어요(같은 파일을 claude.ai 아티팩트에서도 쓰기 위해서). `py-worker.js`가 요청 주소만 바꿔 불러와요.
- scipy 휠은 GitHub·아티팩트 파일 크기 제한 때문에 `scipy/misc`의 예제 데이터 파일(`*.dat`)을 빼고 다시 묶었고, `pyodide-lock.json`의 체크섬도 그에 맞게 바꿨어요.
- 브라우저 파이썬은 스레드를 못 쓰기 때문에 `py/_shim.txt`가 FastAPI의 동기 함수 실행과 `TestClient`를 스레드 없이 돌도록 바꿔요.

## 내 PC에서 열기

```
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`을 열어요. (`file://`로 직접 열면 워커와 파일 불러오기가 막혀요.)
